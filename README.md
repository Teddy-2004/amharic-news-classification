# Amharic News Topic Classification

A comparative study of classical, recurrent, and Transformer-based approaches
to topic classification of Amharic news articles — developed as a summative
project for NLP for the African Context.

**Live demo:** https://huggingface.co/spaces/tedlai/amharic-news-classifier
**Report:** [`report/Amharic_News_Classification_Report.pdf`](report/Amharic_News_Classification_Report.pdf)

## Overview

Given an Amharic news article, this project predicts its topic category
among six classes: ሀገር አቀፍ ዜና (National News), ስፖርት (Sport), ፖለቲካ (Politics),
ዓለም አቀፍ ዜና (International News), ቢዝነስ (Business), and መዝናኛ (Entertainment).

Four modeling approaches were implemented and compared on identical data
splits:

| Model | Accuracy | Macro-F1 |
|---|---|---|
| TF-IDF + Logistic Regression (baseline) | 82.89% | 0.8058 |
| BiLSTM, trained embeddings (unweighted) | 79.26% | 0.7071 |
| BiLSTM, trained embeddings (class-weighted) | 79.09% | 0.7207 |
| **Fine-tuned Amharic BERT-medium (unweighted)** | **87.32%** | **0.8327** |
| Fine-tuned Amharic BERT-medium (class-weighted) | 85.81% | 0.8333 |
| Fine-tuned XLM-RoBERTa-base (unweighted) | 81.94% | 0.7712 |

The best model (fine-tuned, Amharic-specific BERT, unweighted) is the one
deployed in the live demo above. Full methodology, experiment rationale, and
error analysis are in the [project report](report/Amharic_News_Classification_Report.pdf).

### Key findings
- A fine-tuned Amharic-specific Transformer outperforms a same-size
  BiLSTM trained from scratch by over 11 macro-F1 points, and a
  same-hyperparameter multilingual Transformer (XLM-R) by 6.2 macro-F1
  points — despite XLM-R having roughly 7x more parameters.
- Class-weighted loss meaningfully helps the under-trained BiLSTM's rare-class
  (Entertainment) performance, but has no net benefit for the already
  well-pretrained Transformer.
- Across every model tested, the National News category acts as a systematic
  "overflow" category, absorbing the majority of misclassifications from
  every other class — including 86.4% of all Entertainment-category errors.
  Full analysis in Section 7 of the report.

## Dataset

[Amharic News Text Classification Dataset](https://huggingface.co/datasets/rasyosef/amharic-news-category-classification)
(Azime & Mohammed, 2021), accessed via a Hugging Face Hub mirror that
preserves original punctuation. 51,483 articles total, CC-BY-4.0 licensed.
The dataset exhibits a 33x class imbalance between its largest and smallest
categories — see Section 4 of the report for full characterization.

## Setup

```bash
git clone <this-repository-url>
cd amharic-news-classification
python -m venv venv && source venv/bin/activate
pip install -r requirements.txt
```

## Reproducing the Results

**1. Get the data.** Either pull it directly from the Hub:
```bash
python data/download_data.py
```
or, if you have manually downloaded `train.csv` / `test.csv`, place them in
`data/raw/` and run:
```bash
python data/prepare_local_data.py
```

**2. Run EDA** (writes `experiments/eda_report.md` and plots):
```bash
python src/eda.py
```

**3. Train each model.** Each script prints its metrics and appends a row to
`experiments/experiments_log.md`:
```bash
python src/baseline_tfidf_lr.py
python src/bilstm_classifier.py --epochs 10 --class-weights
python src/finetune_transformer.py --model rasyosef/bert-medium-amharic
python src/finetune_transformer.py --model xlm-roberta-base
```

**4. Run error analysis** on any model's predictions:
```bash
python src/error_analysis.py --predictions experiments/results/<run_name>_preds.csv
```

## Model Weights

The final deployed model (fine-tuned Amharic BERT-medium, unweighted) is
published on the Hugging Face Hub at
[`tedlai/amharic-news-classifier`](https://huggingface.co/tedlai/amharic-news-classifier)
rather than committed to this repository, since Git is not well suited to
large binary checkpoint files. `app/app.py` loads it directly from there.

## Running the Deployment App Locally

```bash
pip install gradio
python app/app.py
```
This loads the model from the Hub (see above) and launches a local Gradio
interface. The same `app.py`, plus a minimal `requirements.txt`
(`gradio`, `transformers`, `torch`, `spaces`), is what's deployed to the
live Hugging Face Space linked at the top of this README.
